# Code of conduct

Tab finder follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and constructive, assume good intent, welcome newcomers, and keep discussion about the
work. Harassment, insults, and personal or political attacks aren't accepted in issues, pull requests,
discussions or anywhere else this project lives.

## Reporting

If someone's behavior concerns you, use GitHub's "Report content" option on the comment, or report the
account to GitHub. Maintainers review reports, keep them confidential, and may edit or remove content,
or block people who break this code.
